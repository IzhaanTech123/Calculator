# 🧮 Python Calculator

A simple command-line calculator built using Python. This project is designed for beginners who want to learn Python functions, user input, conditional statements, and basic arithmetic operations.

## 📌 Features

- Addition (`+`)
- Subtraction (`-`)
- Multiplication (`*`)
- Division (`/`)
- User input for numbers and operators
- Basic operator validation
- Beginner-friendly Python code

## 🛠️ Technologies Used

- **Language:** Python 3
- **Concepts:** Functions, `input()`, `float()`, `if-elif-else` statements, and arithmetic operators

## 🚀 Installation and Setup

### 1. Install Python

Download and install Python 3 from the official website:

https://www.python.org/downloads/

Verify the installation by running:

```bash
python --version
```

### 2. Clone the Repository

Open your terminal or VS Code terminal and run:

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

Replace `YOUR_GITHUB_REPOSITORY_URL` with your actual GitHub repository URL.

### 3. Navigate to the Project Folder

```bash
cd Python-Calculator
```

### 4. Run the Program

```bash
python calculator.py
```

On some systems, use:

```bash
python3 calculator.py
```
